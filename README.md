# TPS Shooter Prototype

Играбельный вертикальный срез шутера от третьего лица (TPS) на Unity с уровнем из трёх связанных зон, двумя типами противников на конечных автоматах, шестью видами оружия, системой подбора предметов, миникартой, 3D-звуком и полным игровым циклом.

---

## Сборка и запуск

* **Версия Unity:** `2022.3.62f3` (строго)
* **Рендер-пайплайн:** Universal Render Pipeline (URP)
* **Рабочая ветка:** `tps_shooter`

### Инструкция по запуску из чистого клона
1. Склонируйте репозиторий и переключитесь на ветку `tps_shooter`:
   ```bash
   git clone <URL_вашего_репозитория>
   git checkout tps_shooter
   ```
2. Откройте корневую папку репозитория через **Unity Hub** на версии **2022.3.62f3**.
3. Дождитесь импорта ассетов и компиляции скриптов (в репозитории сохранены все `.meta` и `.dll` плагинов).
4. Откройте стартовую сцену `Assets/_Project/Scenes/MainMenu.unity` (прописана первой в *File → Build Settings*) и нажмите **Play**.

## Управление

Управление реализовано через **Unity Input System** с разделением на карты действий `Player` и `UI` (переключаются автоматически при открытии меню паузы или карты):

| Действие | Клавиша / Кнопка |
| :--- | :--- |
| Перемещение | `W` `A` `S` `D` |
| Обзор / Прицеливание | `Мышь` |
| Режим прицеливания (ADS) | `ПКМ` (удержание) |
| Стрельба / Атака | `ЛКМ` |
| Ближний бой (нож/приклад) | `V` / `F` |
| Перезарядка | `R` |
| Бег (Спринт) | `Left Shift` |
| Приседание | `Left Ctrl` / `C` |
| Прыжок | `Space` |
| Взаимодействие / Подбор | `E` |
| Смена оружия | `1`–`5` или `Колесо мыши` |
| Полноэкранная карта | `Tab` |
| Пауза | `Esc` |

## Реализованные механики (по разделам ТЗ)

### 1. Персонаж и камера
* Камера от третьего лица на базе **Cinemachine** с плавным переходом в плечевой режим прицеливания (ADS), сужением FOV и замедлением чувствительности поворота.
* Перемещение в базисе камеры, бег, приседание, прыжок, движение по склонам (`Vector3.ProjectOnPlane`).
* Анимации **Mixamo** (8+ клипов): 2D Blend Tree для передвижения и стрейфов в прицеливании, отдельный слой `Animator` с `Avatar Mask` на верхнюю часть тела для стрельбы и перезарядки на бегу.

### 2. Оружие (6 видов)
Параметры каждого оружия вынесены в `ScriptableObject`-конфиги. Снаряды, гильзы, трассеры, декали и VFX переиспользуются через пул объектов:
1. **Пистолет** — точный хитскан (`Physics.Raycast`), бесконечный боезапас, быстрая перезарядка.
2. **Штурмовая винтовка** — автоматический хитскан с динамическим конусом разброса и отдачей камеры.
3. **Дробовик** — 8–12 лучей за выстрел (`RaycastNonAlloc`), падение урона от дистанции, физический толчок (`AddForce`), помповая перезарядка.
4. **Гранатомёт** — физический снаряд (`Rigidbody`) с баллистикой, отскоками и радиусным уроном (`OverlapSphereNonAlloc` + проверка укрытий через `Linecast`).
5. **Рельсотрон / Лазер** — пробивающий до 3 целей луч (`RaycastAllNonAlloc` с сортировкой по дистанции), визуализация через `LineRenderer`, асинхронная зарядка выстрела и шкала перегрева.
6. **Оружие ближнего боя** — всегда доступно по отдельной кнопке, поиск целей через `OverlapSphereNonAlloc` + проверка переднего сектора (`Vector3.Dot`), нанесение урона в кадр удара через `Animation Event`, повышенный урон в спину.

### 3. ИИ противников
Навигация построена на запечённом `NavMesh` (`NavMesh.asset` закоммичен в репозиторий) и компоненте `NavMeshAgent`. Поле зрения (`FieldOfView`) использует `OverlapSphereNonAlloc` по таймеру, проверку угла обзора (`Vector3.Angle`/`Dot`) и прямой видимости (`Linecast`), а также визуализируется в редакторе через `OnDrawGizmosSelected` с цветовой индикацией текущего состояния:
* **Стрелок (дальний бой):** `Patrol` → `Alert` → `Combat` (стрельба с упреждением и разбросом) → `TakeCover` (поиск укрытия рейкастами при низком HP) → `Search` → `Dead`.
* **Штурмовик (ближний бой):** `Idle` → `Chase` → `Attack` (урон по `Animation Event`) → `Backstep` → `Stunned` → `Dead`.

### 4. Уровень, физика и интерактив (DOTween)
* Уровень состоит из **3 связанных зон** с разным освещением и эмбиентом, соединённых физическими дверями и лифтом (без телепортов).
* **Физика и разрушаемость:** взрывающиеся бочки с цепной детонацией (`AddExplosionForce`), разрушаемые ящики с разлётом и автоудалением обломков, триггер-зоны урона, чекпоинтов и спавна волн, настроенная `Layer Collision Matrix`.
* **Интерактивные объекты на DOTween (5+ типов):** раздвижные и распашные двери (в том числе по ключ-карте), движущийся лифт/платформа, ловушки (шипы/лазеры), анимация подбора пикапов и анимации UI.

### 5. Подбор предметов, миникарта, звук и игровой цикл
* **Пикапы (`IPickable`):** аптечки, патроны по типам, новое оружие, ключ-карты, шанс выпадения лута с врагов.
* **Миникарта и 2D:** ортографическая камера с рендером в `RenderTexture`, 2D-маркеры из пула с привязкой к краям миникарты (Clamp), полноэкранная карта по `Tab` с легендой.
* **Звук:** `AudioMixer` (`Master` → `Music`, `SFX`, `UI`, `Ambient`), эффекты `Reverb` и `Lowpass` через `Snapshots`, пул 3D-источников звука со случайным `pitch`, звуки шагов в зависимости от поверхности (определяется рейкастом).
* **Игровой цикл:** главное меню, настройки (громкость по логарифмической шкале в `PlayerPrefs`, чувствительность мыши, инверсия), асинхронная загрузка с прогресс-баром, пауза, победа, поражение и рестарт.

## Архитектура и паттерны проектирования

| Паттерн | Класс / Файл | Зачем применяется |
| :--- | :--- | :--- |
| **State Machine** *(обязательный)* | `StateMachine`, `IState`, `PatrolState`, `CombatState`, `ChaseState` и др. (`Scripts/Infrastructure/StateMachine`, `Scripts/Enemies/`) | Изолирует логику поведения противников по отдельным классам состояний без громоздких `switch` в `Update`. |
| **Object Pool** | `ObjectPool<T>`, `ProjectilePool`, `VfxPool`, `AudioSourcePool` (`Scripts/Infrastructure/Pools`) | Переиспользует снаряды, гильзы, декали, VFX, маркеры миникарты и `AudioSource` без аллокаций и `Instantiate`/`Destroy` в бою. |
| **Factory** | `IEnemyFactory` / `EnemyFactory`, `IProjectileFactory` / `ProjectileFactory`, `IPickupFactory` (`Scripts/Infrastructure/Factories`) | Инкапсулирует создание игровых сущностей и прокидывание в них зависимостей через DI без привязки к `PlaceholderFactory`. |
| **Observer** | События `event Action` в `PlayerHealth`, `WeaponInventory`, `LevelStateService` (`Scripts/Player`, `Scripts/UI`) | Связывает игровые модели с HUD и системой целей: UI обновляется реактивно по событиям и не опрашивает игрока в `Update`. |
| **Strategy** | `IFireStrategy`, `HitscanFireStrategy`, `ProjectileFireStrategy`, `PiercingRayStrategy` (`Scripts/Weapons`) | Позволяет гибко менять баллистику и механику стрельбы оружия без дублирования кода и `switch (weaponType)`. |

## Внедрение зависимостей (Zenject)

* **`ProjectContext` (`ProjectInstaller`):** регистрирует глобальные сервисы уровня всего приложения (`IInputService`, `IAudioService`, `ISceneLoaderService`) как `AsSingle()`.
* **`SceneContext` (`GameplaySceneInstaller`):** регистрирует сервисы игровой сцены (`ILevelStateService`), фабрики (`IEnemyFactory`, `IProjectileFactory`, `IPickupFactory`), конфиги (`ScriptableObject` через `FromInstance` / `ScriptableObjectInstaller`) и ссылки на объекты сцены (`Player` через `FromComponentInHierarchy`).
* В коде проекта полностью исключены `FindObjectOfType`, `GameObject.Find`, статические синглтоны и `Resources.Load`.

## Асинхронность (UniTask)

Асинхронные операции реализованы на базе **UniTask** (проверено в *Window → UniTask Tracker* — утечек задач при смерти и рестарте нет):
1. **Перезарядка оружия и зарядка рельсотрона** — с мгновенной отменой через `CancellationToken` при смене оружия или смерти игрока.
2. **Последовательности и кулдауны атак ИИ** — с отменой через `CancellationTokenSource` при смене состояния или смерти врага.
3. **Спавн волн противников и таймеры уровня** — привязаны к токену жизни спавнера/сцены.
4. **Асинхронная загрузка сцен** — `LoadSceneAsync` с плавным отображением прогресс-бара на экране загрузки.
5. **Периодические эффекты (DoT / HoT)** — лечение аптечкой «по тикам» и урон в триггер-зонах с отменой при выходе из зоны или гибели персонажа.

## Структура проекта

```text
Assets/
├── Plugins/                        # Сторонние плагины (Extenject/Zenject, DOTween, UniTask)
├── Resources/                      # ProjectContext.prefab для глобального DI-контейнера
├── Settings/                       # Настройки рендера URP
│
└── _Project/                       # Основная директория проекта
    ├── Art/                        # Графика и анимации
    │   ├── Animations/             # Анимации, Animator Controllers и Avatar Masks
    │   ├── Materials/              # Настроенные материалы окружения, персонажей и декалей
    │   └── VFX/                    # Префабы систем частиц (выстрелы, взрывы, попадания)
    ├── Audio/                      # Аудиоресурсы
    │   ├── Clips/                  # Звуковые эффекты и музыка по категориям
    │   └── Mixer/                  # AudioMixer с группами (Master, Music, SFX, UI, Ambient) и Snapshots
    ├── Configs/                    # ScriptableObject-конфиги (без хардкода в скриптах)
    │   ├── Enemies/                # Конфиги характеристик и ИИ противников
    │   ├── Level/                  # Конфиги волн спавна и настроек уровня
    │   ├── Player/                 # Конфиги передвижения, камеры и здоровья игрока
    │   └── Weapons/                # Конфиги всех 6 видов оружия
    ├── Prefabs/                    # Готовые префабы сцены и объектов спавна
    │   ├── Enemies/                # Префабы противников с настроенными хитбоксами и NavMeshAgent
    │   ├── Environment/            # Интерактив (двери, лифт, ловушки), взрывные бочки, разрушаемые ящики
    │   ├── Pickups/                # Аптечки, патроны, оружие, ключ-карты
    │   ├── Player/                 # Префаб персонажа и камер Cinemachine
    │   ├── UI/                     # Экраны меню, HUD, маркеры миникарты
    │   └── Weapons/                # Префабы оружия, снарядов и гильз
    ├── Scenes/                     # Игровые сцены (MainMenu, Gameplay) и запечённый NavMesh.asset
    ├── UI/                         # UI-спрайты, иконки, маркеры миникарты, InputActions
    │
    └── Scripts/                    # Исходный код, разделённый по подсистемам
        ├── Enemies/                # Логика ИИ, Field of View с Gizmos и отдельные классы состояний FSM
        ├── Infrastructure/         # Архитектурный каркас
        │   ├── Factories/          # Интерфейсы и реализации собственных фабрик (враги, снаряды, пикапы)
        │   ├── Installers/         # ProjectInstaller и GameplaySceneInstaller (Zenject)
        │   ├── Pools/              # Object Pool для снарядов, гильз, декалей, VFX и AudioSource
        │   └── StateMachine/       # Базовая машина состояний (StateMachine, IState)
        ├── Level/                  # Логика окружения
        │   ├── Destructible/       # Взрывающиеся бочки и разрушаемые препятствия
        │   ├── Interactive/        # Двери, лифты и ловушки на DOTween
        │   ├── Pickups/            # Интерфейс IPickable и логика подбора предметов
        │   └── Triggers/           # Триггер-зоны (урон, чекпоинты, спавн волн)
        ├── Player/                 # Движение, прицеливание (ADS), здоровье и инвентарь игрока
        ├── Services/               # Глобальные и сценовые сервисы
        │   ├── Audio/              # IAudioService (работа с AudioMixer и пулом источников звука)
        │   ├── Input/              # IInputService (обёртка над новой Unity Input System)
        │   ├── LevelState/         # ILevelStateService (отслеживание целей, победа и поражение)
        │   └── SceneLoader/        # ISceneLoaderService (асинхронная загрузка сцен через UniTask)
        ├── UI/                     # Интерфейс пользователя (обновляется реактивно по событиям)
        │   ├── HUD/                # Здоровье, патроны, динамический прицел, индикатор урона
        │   ├── Minimap/            # Маркеры миникарты (из пула) и полноэкранная карта по Tab
        │   └── Screens/            # Главное меню, пауза, настройки, экраны победы и поражения
        └── Weapons/                # Контракт IWeapon/WeaponBase и реализации 6 видов оружия
```
